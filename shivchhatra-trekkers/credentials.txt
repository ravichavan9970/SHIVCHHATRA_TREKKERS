[A] HOW TO RUN THE SERVERS (Open separate PowerShell windows):
--------------------------------------------------------------------------------

1. START JAVA SPRING BOOT BACKEND SERVER (Port 8080):
   cd D:\shivchhatra-trekkers\backend
   java -jar target\shivchhatra-backend-1.0.0.jar
   (Or: mvn spring-boot:run)

2. START SEPARATED ADMIN PORTAL (Port 5174):
   cd D:\shivchhatra-trekkers\admin-portal
   npm run dev

3. START PUBLIC TREKKERS WEBSITE (Port 5173):
   cd D:\shivchhatra-trekkers\shivchhatra-trekkers
   npm run dev


[B] PRODUCTION BUILD COMMANDS:
--------------------------------------------------------------------------------
1. Recompile Java Backend JAR:
   cd D:\shivchhatra-trekkers\backend
   mvn clean package -DskipTests

2. Build Standalone Admin Portal:
   cd D:\shivchhatra-trekkers\admin-portal
   npm run build

3. Build Public Website:
   cd D:\shivchhatra-trekkers\shivchhatra-trekkers
   npm run build
